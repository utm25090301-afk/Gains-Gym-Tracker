# 🏋️ GymTracker - Solana

Programa en Solana que permite a los usuarios registrar su progreso en el gimnasio, guardando el peso y series de sus ejercicios principales.

---

## 📋 Descripción

GymTracker es un smart contract desarrollado en Solana usando Anchor Framework. Permite a cada usuario crear su perfil y registrar su progreso en:

- **Press de Banca** 🏋️
- **Sentadilla** 🦵

Toda la información queda guardada en la blockchain de Solana.

---

## ⚙️ Funciones

| Función | Descripción |
|---------|-------------|
| `crear_perfil` | Crea el perfil del usuario con su nombre |
| `registrar_press_banca` | Guarda el peso (kg) y número de series |
| `registrar_sentadilla` | Guarda el peso (kg) y número de series |

---

## 🛠️ Tecnologías

- **Solana** - Blockchain
- **Anchor** - Framework de desarrollo
- **Rust** - Lenguaje de programación
